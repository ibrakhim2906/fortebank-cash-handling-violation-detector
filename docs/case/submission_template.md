## 1. Доступ (R60)
- Сервис (интерфейс): `https://…`
- API: `https://…/api/v1/analyze`, `https://…/api/v1/jobs/{job_id}`

## 2. Инструкция по запуску и использованию (R61)
- Пользователь: открыть ссылку → загрузить .mov → дождаться результата → вердикт, нарушения, кадры, нормы.
- API: пример curl (POST + GET).
- Развёртывание: `scripts/get_models.sh`, `uv sync`, `API_KEY=… uv run uvicorn service.app:app`, или `docker run`.

## 3. Архитектура, подход, модели (R62)
- Схема: видео → кадры 2 fps → детектор → трекинг → автокалибровка сцены → временная шкала фактов → декларативные правила → нарушения + доказательства + нормы.
- Почему так: открытый перечень нарушений → правила редактируются без переобучения; устойчивость к ракурсу через относительную геометрию.
- Модели и лицензии: таблица (модель · назначение · лицензия · источник весов).
- Локальность: все модели внутри сервиса, без облачных API; после загрузки весов интернет не нужен.

## 4. Нормативные источники и сопоставление (R63)
- Акты (из `docs/case/legal.md`): название, дата, номер, ссылка.
- Таблица: тип нарушения → видимый признак → факт → правило → пункт акта (цитата).

## 6. Ограничения и известные ошибки (R65)
- Метрики на обучающих видео (из eval): точность, полнота, ложные срабатывания, точность таймкода, время.
