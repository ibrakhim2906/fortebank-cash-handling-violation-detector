# Jury and ForteBank expectations

> Fill this in during the first 2 hours. Talking to ForteBank mentors is the cheapest edge you have.

## Questions to ask ForteBank mentors / case presenters
1. What decision will this model or analysis support? Who uses it day to day?
2. What do you use for this today? What is wrong with it?
3. What would make you actually deploy a solution like this? (explainability, speed, regulator, integration)
4. Which mistake is more expensive: missing a positive, or a false alarm? Rough ₸ numbers?
5. How are teams judged: leaderboard score, presentation, or both? Weights?
6. Pitch length? Q&A length? Live demo expected? Submission format?
7. Is there anything in the data you already know is tricky or noisy?
