# Local action labeling and the next detection stage

The human requests autonomous action-specific labeling and further detection improvements. This extends the completed MobileNet experiment; it does not reverse the decision to reject its candidates. Work on labels and the next representation is authorized, while new dependencies still require the human's explicit approval under AGENTS.md.

1. Preserve original labels, raw deliveries, the frozen protocol and all eight reserved clips. Build a development-only review queue using the 32 content groups and existing official timestamp anchors. Retain both disputed anchors without choosing between them.
2. Define directly observable action primitives. A negative violation label does not mean the absence of routine actions. Do not infer an action type, complete boundaries, exhaustive coverage or a legal conclusion from a binary label/timestamp.
3. Keep official weak labels, local-model proposals and human-reviewed action labels separate, with hashes, model/recipe provenance and append-only revisions. Unreviewed intervals and uncertain observations remain unknown. Proposals must not silently enter verified-label metrics or supervised training.
4. Build a local operator labeling workflow with playback near anchors and a compact review form. Media, action descriptions and labels stay on the computer. Only aggregate counts/status may be emitted to tools. No media is displayed to this cloud coding assistant: the case explicitly forbids sending footage, frames or their descriptions to cloud AI.
5. Inspect available local vision runtimes and verify a commercially permitted, CPU-suitable vision-language model. Prefer existing installed components. If another runtime/package is needed, prepare the integration and exact download/license/size information first, then request that specific dependency approval. No dependency or model-runtime installation occurs before approval.
6. Local vision may draft action proposals; its own outputs cannot provide independent verified truth. Ask the human only for a short local review of uncertain/representative proposals and any required dependency approval. Do not request clip descriptions or screenshots in chat.
7. Train action-supervised variants only after sufficient independently reviewed labels exist, and fit learned stages inside the unchanged outer folds. Predeclare a bounded action-focused feature/model trial, evaluate against original binary targets and reviewed action labels, run training/sanity, and report actual before/after results. Do not retrain on placeholders or manufacture an improvement while prerequisites are missing.

Fixed pretrained model observations may separately be used as detector inputs and evaluated against original independent binary labels, without treating those observations as verified action targets. That route must use label-independent interval selection rather than organizer timestamps, and does not establish action-type accuracy. Its predeclared next-step plan is `docs/action_detection_trial.md`.

Current quality reference: numeric live baseline AUC 0.509804, recall 10/17; rejected MobileNet clip candidate AUC 0.588235, recall 8/17. The local service remains available during this work. No public deployment, submission, commit or push is authorized by this step.
